# Ehtmam Platform Backend

Backend system for a caregiving platform built using Node.js and Express.js.

## Features
- User Authentication & Authorization (JWT)
- Caregiver Management
- RESTful APIs
- Payment Gateway Integration
- MongoDB Database
- Chatbot Support APIs

## Technologies Used
- Node.js
- Express.js
- MongoDB
- JWT
- Postman
- GitHub

## API Features
- Register & Login
- Protected Routes
- Care Request Management
- Payment Processing
- Chat APIs
